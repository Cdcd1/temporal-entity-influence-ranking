# Temporal Entity Influence Ranking: Datasets

This repository contains public data used in a study of entity influence ranking in temporal heterogeneous networks.

| Dataset | Description | Source and files |
| --- | --- | --- |
| FinDKG | Dynamic financial knowledge graph | [Original repository](https://github.com/xiaohui-victor-li/FinDKG) |
| HiDy | Dynamic financial knowledge base with time-stamped relations | [Data in this repository](data/HiDy/README.md) · [Zenodo](https://doi.org/10.5281/zenodo.12630355) |
| Higgs | Time-stamped Twitter interactions around the Higgs boson announcement | [Stanford SNAP](https://snap.stanford.edu/data/higgs-twitter.html) |
| OGBN-MAG | Academic graph of papers, authors, and related entities | [Open Graph Benchmark](https://ogb.stanford.edu/docs/nodeprop/#ogbn-mag) |

The `data/` directory contains the HiDy files and a [list of original dataset sources](data/sources/README.md).
