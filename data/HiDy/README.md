# HiDy

HiDy is a dynamic financial knowledge base of entities and time-stamped relations. The original dataset is available from [Zenodo, version 1.10](https://doi.org/10.5281/zenodo.12630355).

| Directory | Contents |
| --- | --- |
| [`raw/`](raw/) | Original HiDy `data.zip` archive |
| [`task/`](task/) | Study data: entities, events, state relations, candidates, time windows, and derived ranking labels |

Original creators: Xinyi Zhu, Jiawei Li, Hao Wang, Liping Wang, Boliang Li, Yanyan Shen, and Lei Chen. Original dataset license: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The files in `task/` were derived from the cited HiDy release.
